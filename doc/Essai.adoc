=== 5. Test Cases

[[TEST-001]]
==== TEST-001 – FPGA Clock Synchronization

*Objective:* OBJ-001  
*Requirement(s):* xref:SPEC_BOARD-REQ-01234[]  
*Type:* Functional test  
*Status:* Draft  

===== Description
Verify that the FPGA synchronizes with the main oscillator within 2 µs after reset.

===== Test Procedure
. Power up the board.
. Trigger FPGA reset.
. Measure time delta between main oscillator rising edge and FPGA internal clock.
. Repeat over 10 cycles.
. Record results.

===== Expected Results
The synchronization delay shall be ≤ 2 µs for all measurements.

===== Acceptance Criteria
Pass if:
* Average synchronization ≤ 2 µs  
* No individual test exceeds 2.2 µs  

===== Traceability
*Covers requirement:* xref:SPEC_BOARD-REQ-01234[]  
*Validated by:* TEST_REPORT-001

ENDTEST

[[TEST-002]]
==== TEST-002 – Clock Phase Compensation

*Objective:* OBJ-002  
*Requirement(s):* xref:SPEC_BOARD-REQ-04567[]  
*Type:* Performance test  
*Status:* Draft  

===== Description
Validate that the FPGA compensates clock phase variations under thermal stress.

===== Test Procedure
. Configure board in thermal chamber.
. Sweep temperature from -40°C to +85°C.
. Log clock phase difference every 10°C.
. Compare phase with reference signal.

===== Expected Results
Clock phase drift shall remain within ±10 ns of reference.

===== Acceptance Criteria
Pass if:
* Maximum drift ≤ ±10 ns over the temperature range.  
* Phase correction loop remains stable.

===== Traceability
*Derived from requirement:* xref:SPEC_BOARD-REQ-04567[]  
*Validated by:* TEST_REPORT-002

ENDTEST
